# Orbit 자율 실행 정책 (0.6)

사용자의 자연어 명령 1건을 **하나의 작업 범위**로 해석합니다. 앱 실행, 화면 읽기, 일반 터치·스와이프·뒤로가기, 웹페이지 탐색과 일반 입력, 새 텍스트 파일 작성 및 메모는 매 단계 다시 승인받지 않습니다. 모델은 실제 도구 반환값과 다음 화면을 확인하며 이어서 결정합니다.

## 동작

- WhatsApp 소유자 에이전트 `server/operator.js` 및 로컬 PC 에이전트 `server/agent.js`는 같은 `server/approval-policy.js`를 사용합니다.
- 소유자는 휴대폰 화면 탐색과 일반 브라우저 조작을 **자연어 명령만으로** 연속 수행합니다. 일반 WhatsApp 가입자는 여전히 소유자 컴퓨터와 갤럭시에 접근할 수 없습니다.
- Android 앱 실행·터치·스와이프·뒤로가기·문자 입력 뒤 ADB UI를 다시 읽고 모델의 다음 판단에 전달합니다. 웹 클릭·입력·키 누름 뒤에는 웹페이지를 다시 읽습니다.
- 기본 최대 40회 모델 판단·도구 실행 단계를 지원합니다. 필요하면 환경변수 `ORBIT_MAX_STEPS=50`으로 조정할 수 있으며 실제 최대 60입니다. 무제한/백그라운드 지속 실행은 아닙니다.
- 작업 완료를 확인할 수 없으면 완료로 꾸미지 않고 제한 또는 오류를 보고합니다.

## 별도 승인하는 경우

- 유료 전화 발신, 휴대폰 스크린샷을 외부 비전 API로 전송, 기존 텍스트 파일 덮어쓰기, 개인 메모 삭제
- 브라우저의 구매·송금·계약·해지 확정·삭제·외부 제출 버튼 등 **결과를 확정하는 동작**
- Android에서도 실제 UI 요소를 조사해 위와 같은 중요한 결과 버튼에만 추가 승인을 요청합니다.
- 이미지 외부 전송은 동일 업무에서 최초 1회 승인 시 후속 화면 검사 동안 승인 범위를 유지합니다.

**중요:** 화면 문구와 요소를 검사하는 승인 판단은 휴리스틱이므로 모든 앱의 위험한 버튼을 완벽히 식별하지 못합니다. 실사용 전에 갤럭시·쇼핑·금융 앱별로 충분히 점검해야 합니다. 민감한 결제·권리 포기를 무조건 안전하게 막는 인증 제품이 아닙니다. 소유자 전용 개인 파일럿으로 사용하세요.

## 확인 범위

`npm test`: 모의 안드로이드·모의 LLM에서 10회 연속 조작과 화면 재확인을 포함하는 테스트를 수행합니다. 실제 USB 연결 휴대폰·실전화·실결제·실WhatsApp 사업자 계정에서는 별도 검증이 필요합니다.
