# Orbit 실행 원칙 · 0.7.1

Orbit은 **하나의 실행 하네스**(`server/operator.js`)로 WhatsApp 요청, 운영실 시연, 기존 PC 채팅을 처리합니다. 더 이상 별도의 `server/agent.js` 실행 루프를 사용하지 않습니다.

사용자의 지시와 대화 맥락을 바탕으로 모델이 다음 행동·도구·오류 대응·질문·중간 보고·최종 보고를 결정합니다. 하네스는 실행 기록, 체크포인트, 사용자 응답과 실제 보고 전송 결과를 보존합니다. 일반적인 클릭·스크롤·입력은 매번 승인받지 않습니다. 운영실에서 확인 모드를 따로 선택할 수 있습니다.

완료 보고에서 **도구 1개 성공 = 목표 달성**으로 계산하지 않습니다. 원래 지시와 실제 실행 기록을 도구가 없는 별도 모델 호출로 재검토해 근거가 부족하면 일부 진행으로 표시합니다. 이는 AI 판단으로서 실제 사업자 결과를 100% 증명하지 못하며, 전화 발신 접수는 협상·해지 성공이 아닙니다.

진행 보고는 모델이 결정한 시점에 발송하며 실패하면 실패를 모델에 알려줍니다. 사용자의 응답 형식이 부적절하면 기존 대기 질문을 보존합니다. 재시작 시 대기 중이던 WhatsApp 요청 및 중단된 실행을 복구하고, 결과 미확인 도구는 중복 실행 전 상태부터 점검합니다.

하네스의 최대 단계 수는 자원 사용량 제한이며, 사용자 목표 달성 여부와는 무관합니다. 실제 Meta·SMS·Twilio·1588 통화·실물 갤럭시는 각각 실기기/실계정 검증이 필요합니다.
