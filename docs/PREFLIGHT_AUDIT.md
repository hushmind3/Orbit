# Orbit 소스 사전 점검 — 2026-10-20

사용자가 처음 설치하기 전에 발견 가능한 문제를 우선 수정한 기록입니다. 자동 검사를 통과했다는 사실은 실전화·실기기 무오류를 뜻하지 않습니다.

## 발견·수정된 실제 실행 결함

1. PC의 구형 React 승인 패널이 제거된 `/api/approval`을 호출하던 부분을 같은 에이전트의 채팅 승인 명령으로 바꿈.
2. 운영실에서 모델이 `request_user_input`으로 질문했을 때 답변 텍스트를 API까지 전달하지 못하던 문제 수정.
3. `계속` 명령이 PC에서는 새로운 업무로 처리되고, 재시작 뒤 로컬 소유자 권한이 끊길 수 있던 문제 수정. 동일 작업 체크포인트를 그대로 사용.
4. 실행 결과를 원장에 기록한 뒤 서버가 중단됐을 때 확인된 작업이 중복 실행될 수 있던 문제를 방지. 같은 operationId의 기록을 복원.
5. 작업이 최종 WhatsApp 보고를 발송하기 전에 완료로 표시되던 문제 및 재시작 중간 상태의 복구 문제 수정.
6. 외부 통화가 종료됐다는 이유로 해지·환불 성공으로 표시하던 문제 수정. `outcome-unverified` / `call-ended-unverified` 상태 사용.
7. 통화가 끝날 때 Twilio 세션을 먼저 삭제하면 늦게 도착하는 서명된 완료 콜백이 403으로 거절되고 보고가 빠지는 문제 수정. 콜백 재시도도 인증 가능한 상태 유지(오래된 세션은 재시작 때 4시간 기준 정리).
8. JSON이 깨진 도구 인자를 `{}`로 치환해 잘못된 행동을 실행할 가능성 차단. 모델에게 올바른 인자로 다시 요청.
9. 최종 목표 검증처럼 도구가 없는 모델 호출에 빈 `tools`/`parallel_tool_calls`를 전송하던 호환성 문제 수정.

## 자동으로 검증한 경로

- Windows/macOS 공통 Node.js 구문 검사, TypeScript/React의 `tsc --noCheck --noEmit` 구문 검사.
- 모의 WhatsApp 가입·웹훅·서명 확인·중복 수신 차단·응답 발송.
- 모델 함수 호출, 10회 이상 연속 도구 사용, ADB 명령, 질문/승인 뒤 재개.
- 실제 실행 원장과 완료 보고 비교, 거짓 완료 거부, 오류 및 진행 보고.
- 중단 후 로컬 업무 재개, 잘못된 JSON 도구 인자 거부, 관리자 HTTP 질문 답변, Twilio 종료 서명 재인증과 협상 성공/통화 종료 구분.

## 아직 증명되지 않은 사항

- 이 실행 환경에서 외부 npm 레지스트리 접근이 완료되지 않아 React/Vite 의존성을 설치할 수 없었고, **`npm run build` 완료는 미검증**입니다. TypeScript 구문 검사까지만 진행했습니다. GitHub Actions에서 설치·테스트·빌드를 자동 실행하도록 `preflight.yml`을 추가했습니다.
- Meta 실제 WhatsApp 번호·SMS, Twilio 국내 발신·1588·1544, 실제 Galaxy S25, 실제 모델의 연속 작업·웹 UI, 실제 환불·해지 협상 성공률은 실계정/실기기 검증 전입니다.
- 외부 제공업체가 메시지를 접수하는 것과 수신 단말에 전달되는 것은 다릅니다. Meta 전달 상태 콜백까지 확인하는 완전한 메시지 수신확인 시스템은 아직 없습니다.
- `ORBIT_MAX_STEPS`는 모델 사용량 상한이며 한도 도달 시 대기/재개로 처리합니다. 대외 서비스의 고가용성·복수 서버 동시 실행은 별도 검증 대상입니다.
