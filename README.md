# Orbit — 말로 지시하는 개인 AI 비서 (Windows first)

인스팅트와 동일한 서비스가 아닌, **실제 PC / 브라우저 작업을 실행하는 로컬 에이전트 MVP**입니다.

## 설치 및 실행

1. Windows 11, Node.js 22 이상, Chrome 또는 Edge 설치.
2. Ollama를 설치하고 도구 호출(tool calling)을 지원하는 모델 하나를 내려받습니다. 예: `ollama pull qwen3:4b` (선택 사항: 다른 Ollama 모델이나 OpenAI 호환 API).
3. `start-windows.bat` 더블클릭. 첫 실행 시 `npm install`과 UI 빌드가 수행됩니다. **앱스토어 설치·수수료 없음.**
4. 열리는 `http://127.0.0.1:4786`에서 모델을 선택하고 지시합니다. 음성은 Chrome/Edge의 음성 인식(Web Speech API)을 사용합니다. 마이크 권한이 필요하며 브라우저/OS 설정에 따라 음성 인식에 온라인 연결이 필요할 수 있습니다.

macOS에서도 `start-mac.command`를 통해 대화·브라우저 도구를 사용할 수 있습니다. 로컬 애플리케이션 실행은 Windows 중심으로 구현되어 있습니다.

## 실제 기능

- 한국어 음성 명령 → 텍스트 변환 → LLM 실행 → 한국어 음성 답변(TTS)
- 키보드 명령도 동일한 에이전트 경로를 사용
- Windows 메모장/계산기/탐색기/그림판 실행
- 웹 브라우저를 새 프로필로 구동하여 방문/텍스트 읽기/클릭/입력/키 누르기
- 데스크톱/다운로드/문서 폴더 내 파일 탐색 및 텍스트 읽기/쓰기
- 영구 메모 기록과 이전 대화 복원 (`.runtime/` 폴더, PC 안에만 저장)
- 브라우저 클릭, 입력, 파일 쓰기는 **실행 전에 승인 버튼** 표시
- 작업별 로그, Ollama 모델 목록 확인, OpenAI 호환 API 수동 연결

## 예시 명령

- `메모장 열어줘`
- `구글에서 건축 뉴스 검색해줘`
- `다운로드 폴더에서 최근 파일 10개 보여줘`
- `네이버 홈페이지 열고 주요 기사 제목 읽어줘`
- `이 내용을 기억해 둬: 다음 회의는 목요일` (메모 저장은 승인 후 수행)
- `문서 폴더에 회의 메모.txt 만들어줘` (승인 후 저장)

## 현재 범위

- 실제 전화 발신, SMS, 자동 결제, 로그인 정보 자동 추출, 다른 앱의 비공개 데이터 읽기, OS 전체 화면 클릭은 **아직 구현하지 않았습니다**.
- 웹 조작은 서비스의 로그인 및 차단 정책에 따라 제한됩니다. 은행/결제 같은 민감 작업은 자동화하지 않는 구조입니다.
- 별도 클라우드 서버나 앱스토어 계정은 필요 없습니다. AI 모델은 로컬 Ollama를 권장하며, API 모드 선택 시 대화 내용이 선택한 제공업체에 전송됩니다.
- Chrome/Edge의 음성 인식은 환경에 따라 동작이 달라질 수 있습니다. 음성이 안 되면 문자 입력 및 Windows의 Win+H 음성 타이핑을 사용할 수 있습니다.

## 개발

```bash
npm install
npm run server  # API :4786
npm run dev     # 프론트 개발 :5173 (별도 터미널)
npm test
npm run build
```

## 연결 설정

- 기본: Ollama `http://127.0.0.1:11434`, 예시 모델 `qwen3:4b`.
- OpenAI-compatible: UI에서 공급자 `OpenAI 호환` 선택 후 API 기본 주소(ex: `https://example.com/v1`)·모델명·키 입력. 키는 브라우저의 `sessionStorage`에만 저장되며 브라우저를 닫으면 사라집니다.
- 운영 서버는 `127.0.0.1`에만 바인딩하며, 외부 접속을 허용하지 않습니다.

## 설계

```text
음성/문자 (Chrome/Edge)
       │
 React/Vite/TS UI ── 작업 로그·승인 인터페이스
       │
 Node.js HTTP server (127.0.0.1)
       │
 Ollama / OpenAI 호환 LLM (tool calling)
       ├── Windows 앱·파일 도구
       ├── Playwright + Edge/Chrome (독립 브라우저 프로필)
       └── .runtime/ (대화·메모)
```

## 보안 설계

로컬 서버는 오직 루프백 주소에 개방하고, API 요청에 전용 헤더와 동일 출처 확인을 요구합니다. LLM의 도구 인수는 별도 검사 후 처리합니다. 데이터 변경 동작은 사용자 승인이 필요합니다. 단, 이 MVP를 인터넷에 노출하거나 관리자 권한으로 실행하지 마세요.

## Orbit Phone Lab 0.2 — 전화·협상·갤럭시 실험

**바로 켜기 (AI 전화 연습 화면은 프론트 빌드가 필요 없습니다)**

- Windows: `start-phone-windows.bat` 더블클릭.
- macOS: `bash start-phone-mac.command`.
- 또는 `node server/index.js` 실행 후 `http://127.0.0.1:4786/phone` 열기.
- 가입 없이 개인 실험용입니다. **실제 AI 응답**을 보려면 Ollama(예: `qwen3:4b`, 도구호출 불필요) 또는 OpenAI 호환 API의 주소·모델·키를 화면에서 설정해야 합니다.

### 먼저 시험할 순서

1. **상담 목표** 생성: 원하는 결과, 계약/수리/주문 경위, 절대 양보 못 할 조건 입력.
2. 상담원이 한 말을 그대로 입력하거나 PC 마이크로 받아쓰기.
3. **AI 대응 생성**: 모델이 지금 할 말, 근거, 승인 필요 여부, ARS 키패드 번호를 제안합니다. 긴 대화도 상담 건 단위로 로컬에 유지됩니다.
4. **갤럭시 연결**: Windows/Mac에 Android Platform Tools(ADB)를 설치하고 휴대폰 개발자 옵션에서 USB 디버깅을 허용합니다. `adb devices`에 1대가 연결돼 있어야 합니다. **갤럭시 전화 앱 열기**는 저장된 전화번호로 다이얼러를 여는 작업이며, 실제 통화를 자동으로 건다는 뜻이 아닙니다. 통화 음성을 읽거나 통화 마이크로 AI 목소리를 전송하지 않습니다.
5. **중복 사진 검사**: PC의 `~/Pictures`, `~/Downloads`에서 동일 바이트의 사진만 찾아 목록을 보여줍니다. 삭제는 하지 않습니다. 휴대폰 사진은 PC로 동기화한 후 검사할 수 있습니다.

### 실제 AI 발신 (Twilio 연동 선택 사항)

실제 발신은 통신 제공업체와 연결되어야 합니다. 아래 환경변수를 설정하고 **외부 HTTPS에서 Orbit 서버의 `/twilio/*` 웹훅에 연결되는 환경**을 구축해야 합니다.

- `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM` (`+1...` 등 통신사가 발급한 발신번호)
- `ORBIT_PUBLIC_URL` (공개 HTTPS 주소, 예: `https://orbit.example.com`; HTTPS 터널도 가능)
- 통신사 계정이 없을 때 발신 버튼은 **명확한 미설정 오류**를 보여줍니다. 발신 번호는 `+82...` 등의 국제 표준 E.164 번호여야 합니다.
- 1588·1544 등 국내 대표번호는 Twilio 발신이 보장되지 않습니다. 국내 통신사/SIP 라우팅은 별도 연동 대상입니다.
- 통화 흐름: Twilio Calls REST → 발신 → TwiML 한국어 음성 안내 → 한국어 STT/DTMF → LLM 협상 판단 → TTS로 발언 → 다음 응답. 발신은 화면에서 확인한 뒤 수행합니다.
- 새 계약·추가 결제·권리 포기 등은 AI가 합의하지 않도록 지시되어 있으며 `approval` 판단 시 전화가 종료되고 직접 확인이 필요합니다. AI 모델이 모든 조건을 정확히 파악한다고 보장하지 않습니다.
- 전화망·실제 한국 대표번호·실제 갤럭시 테스트는 아직 수행되지 않았습니다. 통화료와 AI API 요금은 해당 공급자가 청구합니다.

### 같은 Wi-Fi의 휴대전화 브라우저에서 열기

로컬 망 접근을 명시적으로 켜는 경우에만 아래 옵션을 설정합니다. 코드 없이 `0.0.0.0` 공개를 권장하지 않습니다.

- macOS/Linux: `ORBIT_HOST=0.0.0.0 ORBIT_PAIRING_TOKEN=길고임의의12자이상비밀번호 node server/index.js`
- Windows PowerShell: `$env:ORBIT_HOST='0.0.0.0'; $env:ORBIT_PAIRING_TOKEN='길고임의의12자이상비밀번호'; node server/index.js`
- 스마트폰 Chrome에서 `http://PC의_내부IP:4786/phone`을 열고 **AI 모델 연결 화면 위의 페어링 코드**에 같은 비밀번호를 넣습니다.
- LAN으로 HTTP 접속한 브라우저에서는 마이크 음성 인식이 제한될 수 있습니다. 텍스트 입력은 사용할 수 있고, 음성은 HTTPS 환경에서 시험할 수 있습니다.
- 이 LAN 방식은 개인망 실험 전용입니다. 서버를 공용 인터넷에 통째로 직접 개방하지 마세요.

### 현재 미구현

- 자동 상담원 대기 탐지·통화 중 사용자에게 넘기기·실시간 통화 오디오 동시 전달, 본인 확인 대리 수행, 카드 결제, 휴대폰 내부 사진 직접 삭제, SMS 자체 송신, 앱스토어 가입·과금.
- 인스팅트급 완전 자율 개인비서 서비스는 아니며 이 버전은 **실제 AI 협상 보조 + 선택형 통신 발신 경로 + 갤럭시 다이얼러 + 로컬 중복 사진 검색의 실험판**입니다.
