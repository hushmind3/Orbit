02 · AI 모델 연결

로컬 모델로 연습하거나 추론 모델 API를 연결할 수 있습니다. API 키는 이 브라우저 탭에만 저장합니다.

03 · 협상 대화 실험

상담을 만드세요

상담원이 한 말을 입력하거나 마이크로 받아 적으세요. 실제 상대방 발언을 기반으로 AI가 다음 말을 제안합니다.

현재 진행 중인 상담이 없습니다.
AI가 새 비용·장기 약정·권리 포기 등을 승인하지 않도록 설계했습니다. 실제 통화에서는 AI가 제안한 내용을 확인하고 사용할 수 있습니다.

04 · 실제 전화 연결

2가지 경로: ① 갤럭시 USB 연결 → 다이얼러 열기 ② Twilio를 연결해 외부 전화번호로 AI가 직접 발신·대화

1588·1544 같은 국내 대표번호는 Twilio 직통 발신이 보장되지 않습니다. 갤럭시 다이얼러 경로는 휴대폰 통화를 시작할 준비 단계이며, 통화 음성을 PC가 자동으로 받는 기능은 별도 연결이 필요합니다.

05 · 중복 사진 검사

PC의 사진·다운로드 폴더에서 파일 해시가 똑같은 중복 이미지를 찾습니다. 어떤 사진도 삭제하지 않습니다.

동작 방식

웹과 PC: Orbit 로컬 서버 · 갤럭시: USB 디버깅 ADB · AI 협상: Ollama/외부 LLM · 자동 발신: Twilio + 공개 HTTPS 콜백.

🔑 가입 없이 개인 실험용입니다. 전화 발신 요금·LLM API 요금은 연결된 계정에 청구됩니다.
